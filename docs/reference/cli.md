# CLI reference

Every `workmesh` command and its options, as `--help` prints them. This page is generated by
`npm run docs:ref` (`scripts/docs-ref.mjs`) from the built CLI; CI fails when it is out of date. To change it, change
the command in `packages/cli/src/index.ts` and run the script again. `agentblip` is an alias for `workmesh`.

For what to run when, start with the [guide](../guide/getting-started.md).

## workmesh init

```text
Usage: workmesh init [options] <hub-url>

Set this machine up for a team hub in one go: hooks, MCP tools, the daemon, and
pairing (safe to run again)

Arguments:
  hub-url              the team's hub, e.g. https://workmesh.b3os.org

Options:
  --share <level>      conversation | metadata (asked when omitted in a
                       terminal)
  --codex              install Codex hooks even when no Codex install is found
  --no-codex           leave Codex's files alone
  --no-open            print the approve link without opening a browser
  --machine <name>     name this machine on the board (default: hostname)
  --claude-dir <path>  Claude Code config dir to hook (default:
                       $CLAUDE_CONFIG_DIR, else ~/.claude)
  --no-mcp             don't register the workmesh MCP server
  --no-service         run the daemon in the background, not under launchd /
                       systemd
  --no-linger          Linux: don't turn on lingering (the daemon then stops
                       when you log out)
  --no-wake            don't install the hook that wakes idle sessions for
                       messages
  --repair             pair again even if this machine is already paired with
                       the hub
  -h, --help           display help for command
```

## workmesh update

```text
Usage: workmesh update [options]

Install the newest Workmesh the way it was installed, refresh hooks, MCP and the
daemon, roll back if it fails (safe to run again)

Options:
  --check          only say what's installed and what's out
  --json           with --check: machine-readable output

  --auto <on|off>  let the daemon install releases on its own, at most daily
                   (patch releases unless --minor)
  --minor          with --auto on: minor releases too
  -h, --help       display help for command
```
